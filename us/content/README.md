# Conteúdo das LPs (us e de)
- `*_v1_rendered.html`: backup v1 (conteúdo renderizado pela API REST pública; o conteúdo bruto exige login).
- `*_v2.html`: v1 com as novas seções inseridas, só para referência e revisão.
- `*_v2_NEW_BLOCKS.html`: **use este**. Blocos Gutenberg (wp:heading/wp:paragraph) para colar no Editor de código, no ponto indicado no comentário do topo. Todo o conteúdo existente (quiz, botões, links, avisos) continua igual.
